## 📊 Project Overview

This repository contains comprehensive **Exploratory Data Analysis (EDA)** and visualization for student placement prediction datasets. The project analyzes multi-dimensional academic, technical, soft skills, and institutional attributes across 50,000 student records to uncover key trends, correlation factors, and indicators driving successful student campus placements.

### 📁 Repository Contents

* **`WEEK1\_EXPLORATARY-DATA-ANALYSIS.ipynb`**: Complete Jupyter Notebook containing data preprocessing, missing value reports, univariate \& bivariate visual analysis, correlation matrices, and distribution metrics.
* **`placement\_all\_graphs/`**: Directory containing all 60+ generated visualization images (bar charts, histograms, pie charts, boxplots, scatter plots, and correlation heatmaps).
* **`README.md`**: Project documentation.

\---

## 📈 Key Dataset Insights \& Highlights

* **Total Records:** 50,000 Students
* **Features Analyzed:** 31 Columns (SGPA 1-8, CGPA, Coding Test Score, Aptitude Score, Soft Skills Rating, Mock Interview Score, Internships, Projects, Certifications, College Tier, Stream, Gender, Backlog History, Placement Status).
* **Placement Rate:** \~65.7% overall placement success.
* **Key Predictors:** High correlation observed between CGPA, Coding Test Score, and Placement Status.
* **Visualizations:** Over 60 detailed charts categorizing student performance, tier distribution, attendance impact, and skill-to-placement mappings stored in `placement\_all\_graphs/`.

## 🚀 Execution \& Requirements

To run the analysis locally:

1. Open `WEEK1\_EXPLORATARY-DATA-ANALYSIS.ipynb` in Jupyter Notebook or VS Code / Google Colab.
2. Ensure required Python packages are installed (`pandas`, `numpy`, `matplotlib`, `seaborn`).
3. Execute all cells to generate updated statistics and graphs in `placement\_all\_graphs/`.
